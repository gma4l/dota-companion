# Dota 2 Draft Assistant

Помощник по драфтингу в Dota 2. Автоматически считывает пики и баны из игры
(через Game State Integration), определяет твою команду и выдаёт **топ-5 лучших
героев по каждой позиции (1–5)** на отдельной веб-странице — с учётом
контрпиков, синергий и ролей.

Дополнительно: **рекомендация банов**, **угрозы** (кто из врагов контрит твою
команду) и **анализ состава 5v5** (закрытые позиции, баланс атрибутов, дыры).
Работает и в капитанском режиме (автоматически), и в **пабликах / All Pick**
(ручной ввод героев).

## Что внутри

- `server.js` — сервер (чистый Node.js, без зависимостей). Принимает GSI-драфт,
  считает рекомендации, раздаёт веб-интерфейс и API.
- `heroes.json` — база всех героев: имя (EN/RU), атрибут, роли (позиции),
  контрпики и синергии.
- `public/` — веб-интерфейс (HTML/CSS/JS).
- `gamestate_integration_draftassist.cfg` — конфиг GSI для Dota 2.

## Требования

- [Node.js](https://nodejs.org) 18+ (проверено на v26).
- Dota 2 в Steam.

## Запуск

```bash
node server.js
```

Открой в браузере: **http://127.0.0.1:3210**

Интерфейс можно проверить **без игры** через «⚙ Демо-режим» — вручную собери
драфт и посмотри рекомендации.

## Подключение к Dota 2 (GSI)

1. В Steam → библиотека → правый клик по **Dota 2** → **Свойства** → вкладка
   **Общие** → в поле **Параметры запуска** впиши:

   ```
   -gamestateintegration
   ```

2. Скопируй файл `gamestate_integration_draftassist.cfg` в папку:

   ```
   <папка Steam>\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\
   ```

   (папку `gamestate_integration` создай, если её нет)

3. Перезапусти Dota 2. Во время драфта (Captains Mode / капитанский драфт) игра
   сама будет присылать пики и баны на сервер — страница обновится автоматически.

## Паблики (All Pick)

В All Pick игра **не** шлёт `draft`-объект (он есть только в Captain's Mode),
поэтому пики вводишь вручную — по мере того как видишь их на экране выбора:

1. Разверни панель **«🖱 Выбор героев вручную»**.
2. Выбери категорию (по умолчанию «Враг · пик»), отфильтруй по атрибуту или
   найди героя поиском.
3. Кликай по портретам — герои сразу попадают в драфт, а рекомендации, баны
   и угрозы обновляются мгновенно.
4. Сторону (Radiant/Dire) можно переключить в шапке, если игра не определила её.

Категории: **Враг · пик**, **Союзник · пик**, **Враг · бан**, **Союзник · бан**.

## Как это работает

- В капитанском режиме Dota 2 шлёт состояние драфта (`draft.team2` = Radiant,
  `draft.team3` = Dire) с полями `pick0_id…pick4_id`, `ban0_id…ban6_id`; сервер
  определяет твою команду по `player.team_name` (`radiant`/`dire`).
- Для каждой позиции 1–5 сервер оценивает всех свободных героев:
  - **+2** за каждого врага, которого герой контрит;
  - **−2** за каждого врага, который контрит героя;
  - **+1.5** за каждого союзника, с которым есть синергия;
  - бонус за соответствие роли и универсальность.
- Выводится топ-5 по каждой позиции с пояснением (кого контрит, с кем синергия).
- **Баны**: ранжирует героев, которые контрят твою команду или усиливают врага.
- **Угрозы**: какие вражеские герои контрят твоих пиков.
- **Состав**: закрытые/свободные позиции, баланс STR/AGI/INT и подсказки.

## API (для разработки)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/dota2-gsi` | Приём GSI-пейлоада от Dota 2 |
| GET  | `/api/state` | Текущий драфт + рекомендации |
| GET  | `/api/heroes` | Список героев |
| POST | `/api/manual` | Демо: ручная установка драфта |
| POST | `/api/reset` | Сброс драфта |
| POST | `/api/side` | Ручной выбор стороны (`radiant`/`dire`) |

Порт можно сменить: `PORT=3333 node server.js` (не забудь поменять `uri` в .cfg).
