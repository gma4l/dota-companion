# Dota Companion

Один инструмент для обычных матчей (All Pick): подсказки по драфту до игры
и разбор матча после. Локальная версия работает на своём ПК и использует
локальную модель Ollama, публичная — на бесплатном хостинге без ИИ.

## Статус

Ранняя сборка: два исходных проекта импортированы без изменений.

| Папка | Что это | Состояние |
|---|---|---|
| `apps/analyzer/` | Анализатор матчей + AI-тренер + трекер прогресса | работает, тесты 23/23 |
| `apps/draft/` | Помощник по драфту (GSI + контрпики) | работает, All Pick — ручной ввод |

План объединения — в [docs/PLAN.md](docs/PLAN.md).

## Требования

- Node.js 18+
- Dota 2 (для GSI)
- Ollama с моделью `qwen3:8b` (только для AI-разбора)

## Быстрый старт

```bat
:: анализатор матчей и прогресса
cd apps\analyzer
start.cmd

:: помощник по драфту (отдельное окно)
cd apps\draft
node server.js
```

- Анализатор: http://localhost:8080
- Драфт: http://127.0.0.1:3210
