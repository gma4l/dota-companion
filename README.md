# Dota Companion

Инструмент для **обычного матчмейкинга (All Pick)**: подсказки по драфту до игры
и разбор матча после. Две версии из одного кода:

| Версия | Где работает | Что умеет |
|---|---|---|
| **Настольная** | твой ПК, Node.js | драфт по GSI, трекер прогресса, разбор матчей, AI-тренер на Ollama |
| **Публичная** | Cloudflare (бесплатно) | драфт вручную, статистика матча по правилам, без ИИ |

## Структура

```
core/          общая логика: герои, контрпики, синергии, скоринг драфта (без HTTP)
apps/analyzer/ анализатор матчей, трекер и AI-тренер (настольная версия)
apps/draft/    веб-интерфейс драфта
local/         единая точка входа и сетевые помощники
worker/        API для публичной версии (Cloudflare Worker)
web/           публичный сайт
docs/PLAN.md   план развития
```

Ключевое: `core/` не зависит от Node-файлов и HTTP, поэтому один и тот же
расчёт драфта работает и на компьютере, и на Cloudflare.

## Настольная версия

Требования: Node.js 18+, Dota 2, Ollama с моделью `qwen3:8b` (для AI-разбора).

```bat
npm start
```

Откроется `http://localhost:8080`:

- `/` — разбор матча и AI-тренер;
- `/progress.html` — трекер прогресса по аккаунту;
- `/draft` — помощник по драфту;
- `/dota2-gsi` — приём данных от игры.

### Подключение к Dota 2

1. Steam → Dota 2 → Свойства → Параметры запуска → добавь `-gamestateintegration`.
2. Скопируй конфиг в папку игры:

```bat
copy apps\draft\gamestate_integration_draftassist.cfg "D:\SteamLibrary\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\"
```

3. Перезапусти Dota 2.

Сторона и твой герой определяются автоматически. **Пики врагов в All Pick
игра не передаёт** — их отмечают в сетке героев (~10 секунд на 9 кликов).
Капитанский режим подхватывается целиком сам.

## Публичная версия

```bat
npm run web:dev
```

Откроется `http://127.0.0.1:8787` — тот же сайт, что будет в интернете.

Деплой (нужен бесплатный аккаунт Cloudflare):

```bat
npx wrangler login
npx wrangler deploy
```

`wrangler.toml` уже настроен: статика из `web/`, API из `worker/index.mjs`.

## Особенности сети

В некоторых сетях (в частности, через DPI) Node не может установить TLS 1.3:
соединение висит и падает по таймауту, хотя браузер и curl работают.
Поэтому настольная версия ходит в OpenDota через TLS 1.2 (`local/net.js`).
Отключить принудительный TLS 1.2: `set FORCE_TLS12=0`.

Публичная версия работает на стороне Cloudflare, там это ограничение не действует.

## Данные

- история матчей — локальная SQLite `apps/analyzer/data/dota.db` (в git не попадает);
- наружу уходят только запросы к публичному API OpenDota;
- AI-разбор генерируется локальной моделью, никуда не отправляется.

## Ограничения

- ИИ есть только в настольной версии: на бесплатном хостинге нет GPU.
- В All Pick врагов вводят вручную; автоматическое распознавание по скриншоту — в планах.
- Чтение памяти игры и инъекции не используются: это риск бана.
