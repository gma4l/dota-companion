# План

## Цель

Обычный матчмейкинг (All Pick), а не Captains Mode.

Ограничение: в All Pick Dota 2 не присылает `draft` через GSI — только твоего
героя и сторону. Пики врагов определяются вручную: быстрая сетка героев
с поиском (~10 секунд на 9 кликов).

## Этапы

1. **Импорт и история.** Оба проекта в одном репозитории, первый коммит. ✅
2. **Общее ядро.** `heroes.json`, алиасы, контрпики, синергии, скоринг драфта,
   расчёт инсайтов — в `core/`, без HTTP. Используется и локальной, и веб-версией.
3. **Единый локальный сервер.** Один порт: драфт + разбор + трекер + GSI.
4. **All Pick как основной режим.**
   - GSI определяет сторону и твоего героя;
   - сетка героев с поиском для врагов;
   - после конца матча — автозагрузка из OpenDota и разбор.
5. **Публичная версия.** Статика + Cloudflare Worker (прокси к OpenDota, кэш
   в D1). Без ИИ: только правила и статистика.
6. **Деплой.** GitHub → Cloudflare Pages, автодеплой по пушу.

## Чего не делаем

- чтение памяти игры и инъекции — риск бана;
- ИИ на бесплатном хостинге — нет GPU, `qwen3:8b` не поедет;
- автоматическое распознавание пиков врагов в v1 — только вручную.

## Что понадобится от владельца

- аккаунт GitHub (бесплатный);
- аккаунт Cloudflare (бесплатный, без карты);
- ключ OpenDota — необязателен, но поднимает лимиты API.
